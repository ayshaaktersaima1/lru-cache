# LRU Cache

A simple Least Recently Used (LRU) Cache implementation in JavaScript.

This project was created as part of a Frontend Developer Intern practical assessment to demonstrate JavaScript problem-solving, data structure usage, and time complexity understanding.

## Requirements

The cache supports:

- `Cache(capacity)`
- `get(key)`
- `put(key, value)`

The required behavior is:

- The cache has a fixed positive capacity.
- `get(key)` returns the stored value if the key exists.
- `get(key)` returns `-1` if the key does not exist.
- A successful `get()` makes that key the most recently used item.
- `put(key, value)` adds a new key/value pair or updates an existing one.
- When the cache exceeds its capacity, the least recently used item is removed.
- `get()` and `put()` run in O(1) average time.

## How It Works

This implementation uses JavaScript's built-in `Map`.

A `Map` keeps entries in insertion order.

The first item in the `Map` is treated as the least recently used item, while the last item is treated as the most recently used item.

When a key is accessed with `get()`:

1. The value is retrieved.
2. The key is removed.
3. The key is inserted again.

This moves the accessed key to the end of the `Map`, making it the most recently used item.

When a new item is added and the cache exceeds its capacity, the first key in the `Map` is removed because it is the least recently used item.

## Example

```js
const LRUCache = require("./src/LRUCache");

const cache = new LRUCache(2);

cache.put("A", 10);
cache.put("B", 20);

cache.get("A"); // 10

cache.put("C", 30);

cache.get("B"); // -1
cache.get("C"); // 30
cache.get("A"); // 10
```

## Time Complexity

### `get(key)`

Average time complexity:

`O(1)`

The implementation uses JavaScript `Map` operations such as `has()`, `get()`, `delete()`, and `set()`.

### `put(key, value)`

Average time complexity:

`O(1)`

Insertion, updating, lookup, and removal are handled using `Map`.

## Space Complexity

The cache stores at most the number of items defined by its capacity.

`O(capacity)`
